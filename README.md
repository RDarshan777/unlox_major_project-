# Retail Analytics & AI-Powered Sales Forecasting System

## 📌 Project Overview
This project analyzes retail sales data across multiple stores and product categories to understand sales performance, identify trends, and forecast future revenue. It includes an interactive dashboard built using Streamlit to present key insights in a simple and visual way.

## 🎯 Objectives
- Analyze retail sales and revenue trends.
- Compare sales performance across stores.
- Understand product category performance.
- Forecast revenue for the next 30 days.
- Segment stores using machine learning.
- Present business insights through an interactive dashboard.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Plotly

## 📊 Key Features
- Sales analysis and key performance indicators (KPIs).
- Interactive date, store, and product category filters.
- Revenue trend visualizations.
- 30-day revenue forecasting.
- Store segmentation using K-Means clustering.
- Automated business insights.

## 📁 Project Files
- `major_project_R_Darshan_reviewed.ipynb` — data analysis and machine learning workflow.
- `app.py` — interactive Streamlit dashboard.
- `Retail_Sales_Data_Unlox.csv` — retail dataset, if included.
- `outputs/` — generated analysis, forecast, and segmentation files, if required by the dashboard.

## 🚀 How to Run the Project

### 1. Install the required libraries
```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit plotly
```

### 2. Place the required files together
Keep `app.py`, the required dataset, and any output files in the correct locations expected by the application.

### 3. Run the dashboard
```bash
python -m streamlit run app.py
```

### 4. Open the dashboard
Open the local URL displayed in the terminal, usually `http://localhost:8501`.

## 💡 Expected Outcome
The project helps users explore retail performance, compare stores and product categories, examine revenue forecasts, and use data-driven insights to support business decisions.
